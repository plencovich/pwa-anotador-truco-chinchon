🃏 Anotador de Truco y Chinchón con IA (PWA)

Una Progressive Web App (PWA) instalable, responsiva y ligera para anotar puntos de Truco y Chinchón, integrada con Inteligencia Artificial (Google Gemini) para resolver dudas de reglamento, generar versos y sugerir jugadas.

✨ Características

🃏 Anotador de Truco

Puntaje visual con fósforos/palitos: Representación tradicional en cuadrados de 5 puntos (línea horizontal, verticales y diagonal).

Malas y Buenas: Separación clara hasta alcanzar los 30 puntos.

Nombres personalizables: Presiona sobre "Nosotros" u "Ellos" para cambiar los nombres de los equipos.

Botones IA:

✨ Consultar Regla: Resuelve dudas del reglamento al instante con Gemini.

✨ Generar Verso: Crea versos tradicionales o chicanas amistosas para cantar envido/truco.

🎴 Anotador de Chinchón

Configuración flexible: De 2 a 6 jugadores con nombres editables.

Ingreso rápido de puntos: Teclado numérico y accesos directos (-10 puntos y -25 por Chinchón).

Eliminación automática: Marca jugadores eliminados al superar los 100 puntos (101+).

Detección de ganador: Determina el ganador cuando queda un solo jugador activo.

Asistente IA: ✨ Sugerir Jugada: Consejos de estrategia rápida según tu mano.

📱 Funcionalidades PWA y Usabilidad

Instalable en el celular: Funciona como una app nativa desde la pantalla de inicio.

Persistencia de datos (Offline/localStorage): Si cierras el navegador o recargas la página, la partida continúa donde la dejaste.

Diseño Responsivo: Optimizado para pantallas móviles con Tailwind CSS y Material Design.

🛠️ Tecnologías utilizadas

HTML5 / CSS3 / JavaScript (Vanilla ES6)

Tailwind CSS (vía CDN)

Google Gemini API (gemini-2.5-flash-preview-09-2025)

Service Worker & Web App Manifest (PWA incorporado en un solo archivo)

LocalStorage API (para persistencia de partidas)
